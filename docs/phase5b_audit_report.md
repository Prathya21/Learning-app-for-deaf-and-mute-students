## PART 3 — Vocabulary Separation Architecture

### Implemented Three-Way Separation

| Vocabulary | Purpose | Scope | Storage |
|------------|---------|-------|---------|
| **Translation Vocabulary** | Glosses NLP can generate from text | 46 glosses (Phrase + Word maps) | `PHRASE_GLOSS_MAP`, `WORD_GLOSS_MAP` in `isl_translation.py` |
| **Gesture Classifier Vocabulary** | Glosses future gesture model will classify | Not yet trained (synthetic prototype) | `class_map.json` in synthetic landmarks |
| **Video Asset Availability** | Glosses with actual MP4 demo videos | 0/46 (no real assets) | `isl_dictionary.json` + filesystem check |

### Key Principles Enforced
1. **Independence** — Three vocabularies are independent; no automatic coupling
2. **Truthful API** — `POST /api/translate/text-to-isl` returns `found: false` when no video file exists
3. **Video Player Safety** — Frontend `ISLVideoPlayer` only attempts playback when `found: true`
4. **Classifier Independence** — Future gesture classifier can support glosses without videos
